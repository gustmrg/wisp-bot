# Voice input

[Voice input](wisp://settings/voice) sets up dictation:

- **Transcription** — the provider (Groq, OpenAI or Mistral), the model, and
  the language you speak, which improves accuracy.
- **Credential** — the provider's API key, the same key
  [AI Model](wisp://settings/model) uses for that provider.
- **Recording** — the microphone, and **Send automatically**: on, the message
  is sent as soon as it is transcribed; off, the text waits in the composer.

Then use the microphone button in the composer, or the shortcut set in
[Shortcuts](wisp://settings/shortcuts). **Esc** cancels a recording. In a
browser, voice input needs an HTTPS address.
