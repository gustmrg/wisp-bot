# Token usage and costs

- [Token usage](wisp://settings/usage) shows totals and a breakdown by Wisp
  for the last 7 days, the last 30 days or all history.
- A Wisp's [Usage](wisp://wisp/usage) page shows its session report: models,
  tokens, tool calls, summaries and retries.

Costs in US dollars are estimates from current public model prices, not
invoices; a cost stays unknown when no price is available. Summaries and the
image model count in the totals.
