# Updates and version

[About](wisp://settings/about) shows the version and checks for updates when
you ask; nothing downloads on its own.

- **Linux** (AppImage and `.deb`) downloads and installs updates in place; the
  `.deb` asks for the administrator password.
- **macOS** builds cannot install updates themselves: About shows the new
  version and opens the releases page to download it.

A Wisp server shows its version in [Connections](wisp://settings/connections)
and warns when it differs from the app's.
