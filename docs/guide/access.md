# Access and approvals

## Approval cards

Some actions need your approval: file changes (depending on auto-review),
integration calls that change something, MCP tool calls, saving a skill and
creating a job. The card shows what will happen; choose **Allow once** or
**Deny**, or, where offered, an **Always allow** or **Always block** choice.
Pending approvals show in the conversation and the sidebar; on a phone they
also have their own tab.

## File changes

**Auto-review file changes** in [General](wisp://settings/general), under
**Wisp**, has one **Allow / Ask / Block** choice for **Create files** and one
for **Modify files**. Turning auto-review off makes every file change ask.
**Always allow** and **Always block** on a file approval card change the same
choices. Wisps only ever change files inside their own workspace.

**Integration blocks**, in the same section, lists the blocks added from
approval cards (such as **Block all integration calls**) and lets you remove
them.

## What a Wisp can use

A Wisp's [Access](wisp://wisp/access) page lists the plugins and MCP servers it
can use and its always-allowed MCP tools. Commands are set in its
[Commands](wisp://wisp/execution) settings.
