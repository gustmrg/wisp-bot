# Web search and plugins

Wisps have no web access until you connect a plugin and give a Wisp access.

## Connect a plugin

Open [Plugins](wisp://settings/plugins), choose a plugin under **Available**,
paste its API key (each form links to where to get one) and select
**Connect**. The key is tested before it is saved. The plugins are:

- **Brave Search** — web search.
- **Firecrawl**, **Tavily**, **Exa** — web search and reading pages.
- **Linear** — read issues, or also create and update them.

A connected plugin's page has **Test connection**, **Replace key**,
**Remove connection** and an **Enabled** switch. With several web providers
connected, **Default web providers** chooses which one is suggested first.

## Give a Wisp access

Connecting grants nothing by itself. In the Wisp's
[Access](wisp://wisp/access) page, under **Web**, choose a provider for
**Search the web** and **Read web pages**; under **Apps**, choose **Read only**
or **Read and write** for Linear; then **Save access**. A plugin's page in
[Plugins](wisp://settings/plugins) offers the same choices for every Wisp at
once. New tools are available from the Wisp's next message.

Creating or changing Linear issues always asks for approval first.
