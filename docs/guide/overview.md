# Where things are

Wisp has two kinds of settings.

## Application settings

Open them from your name at the bottom of the sidebar (**User settings**).
They apply to the whole app and every Wisp.

| Panel | What it holds |
| --- | --- |
| [General](wisp://settings/general) | Your profile (name, about you, response preferences), theme, Wisp colors, launch at login, timezone, auto-review of file changes, integration blocks |
| [Connections](wisp://settings/connections) | Where your Wisps run: this computer or a Wisp server |
| [Remote access](wisp://settings/remote-access) | Use this computer's Wisps from your phone or another device |
| [AI Model](wisp://settings/model) | Default provider and model, provider API keys, output token limit, image model |
| [Voice input](wisp://settings/voice) | Transcription provider, model, language, microphone, send automatically |
| [Plugins](wisp://settings/plugins) | Web search and page reading (Brave Search, Firecrawl, Tavily, Exa), Linear, and which Wisps use them |
| [MCP servers](wisp://settings/mcp) | Outside tools connected over MCP, and which Wisps use them |
| [Jobs](wisp://settings/jobs) | Every scheduled job of every Wisp: pause, resume, run now, delete |
| [Token usage](wisp://settings/usage) | Tokens and estimated cost per Wisp over time |
| [Storage](wisp://settings/storage) | Space used by each workspace, cleanup, archives of deleted Wisps |
| [Notifications](wisp://settings/notifications) | Sounds for finished replies, approvals and errors |
| [Shortcuts](wisp://settings/shortcuts) | Keyboard shortcuts |
| [About](wisp://settings/about) | Version, updates, release notes |

## A Wisp's settings

Open them with the gear in the conversation header (**Open Wisp settings**).
They apply only to that Wisp. On the desktop they are tabs: **General**,
**Model**, **Access**, **Usage**, with **Context & memory**, **Skills**,
**Workspace**, **Commands** and **Jobs** as sections inside **General**. On a
phone they are pages listed on the Wisp's profile.

| Page | What it holds |
| --- | --- |
| [Profile](wisp://wisp/profile) | Appearance, name, role, soul, notifications for this Wisp; share as template; delete |
| [Model](wisp://wisp/model) | The model this Wisp runs on, and its reasoning level |
| [Access](wisp://wisp/access) | Which plugins and MCP servers this Wisp can use |
| [Usage](wisp://wisp/usage) | This Wisp's session report: tokens, cost, tool calls |
| [Context & memory](wisp://wisp/memory) | Context renewal, summaries, new topics, saved memory |
| [Skills](wisp://wisp/skills) | Saved procedures this Wisp follows |
| [Workspace](wisp://wisp/workspace) | This Wisp's private folder and its size |
| [Commands](wisp://wisp/execution) | Running commands in a container, GitHub token, local network |
| [Jobs](wisp://wisp/jobs) | This Wisp's scheduled jobs |
