# Model lab logos

Bundled locally for offline display, from Iconify (https://iconify.design):
- Simple Icons paths in each brand's color: `anthropic`, `openai`, `meta`, `deepseek`, `qwen`, `moonshotai` (Moonshot), `zdotai` (Z.ai), `minimax`, `xiaomi`, `amazon`, `nvidia` (https://simpleicons.org)
- SVG Logos multicolor marks: `google-icon`, `mistral-ai-icon`, `microsoft-icon` (https://github.com/gilbarbara/logos)
- xAI: the `xai` codicon (https://github.com/microsoft/vscode-codicons)

These logos identify the companies that make each model; trademarks belong to their owners.
