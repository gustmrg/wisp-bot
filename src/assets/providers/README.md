# Provider logos

Bundled locally for offline display, from Iconify (https://iconify.design). Providers run by a model lab use its logo from `../model-labs`.
- Simple Icons paths in black: `openrouter`, `vercel` (https://simpleicons.org)
- SVG Logos marks: `cloudflare-icon`, `cerebras-icon`, `togetherai-icon`, `fireworks-ai`, `baseten-icon`, `hugging-face-icon`, `opencode-icon` (https://github.com/gilbarbara/logos)
- Groq: the `groq` mark from theSVG (`thesvg-color`)
- GitHub Copilot: the `copilot` octicon in black (https://primer.style/octicons)

These logos identify their respective services; trademarks belong to their owners.
